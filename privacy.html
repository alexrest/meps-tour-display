MEPS Tour Display Gmail integration

Last updated: October 3, 2026

MEPS Tour Display uses Google's Gmail API to send souvenir PDFs requested at the tour kiosk. A guide authorizes the sender account; visitors do not authorize Google account access.

Google account access

The app requests permission to send email (gmail.send) and to verify the connected account's email identity (openid email). It checks that the account is meps.am.tour@gmail.com. It does not request permission to read the inbox, list existing messages, access contacts, or manage the account's mail settings.

Google account information is used to verify the designated sender and deliver requested souvenirs. Google user data is not used for advertising, sold, or used to train artificial-intelligence models. MEPS Tour Display's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Stored information

The sender's OAuth client configuration and refresh token are stored in the operating system's credential store for the user running the kiosk: Windows Credential Manager, or macOS Keychain for developer testing. Tokens are not stored in the browser, the shared PDF folder, application logs, or the source repository.

Each requested souvenir is associated with the visitor-provided recipient address and the matching PDF in a local archive. Delivery records store sending status, attempt counts, timestamps, safe error messages, and Google's message confirmation identifier. The kiosk retains archives and delivery records; it does not automatically delete them.

Souvenir PDFs and image-diagnostic sidecars are also copied to the configured office shared folder. The Gmail token and recipient records are not copied there.

Email delivery

When delivery is enabled, the app transmits the recipient address, a short thank-you message, and the souvenir PDF to Google for sending. The PDF may include the visitor's tour content and souvenir picture. Google processes the email, and the recipient's email provider processes and stores the delivered message. Sent messages may remain in the sender's Gmail account according to that account's settings. The kiosk cannot guarantee delivery or inbox placement.

This notice describes the Gmail integration. The tour's picture-generation, printing, and local/shared souvenir storage also operate independently of Google account authorization.

This information website

This site is hosted by GitHub Pages. It has no email-entry form, analytics scripts, or application sign-in. GitHub logs visitors' IP addresses for security purposes. See the GitHub Privacy Statement for the hosting provider's practices.

Control and contact

A guide can pause automatic delivery or disconnect the kiosk. Disconnecting removes that kiosk's saved refresh token; the guide can also revoke the app's Google authorization through the sender's Google Account connections settings. Pausing prevents future attempts; an email already in transmission may finish.

For questions about this integration or requests concerning a souvenir archive, contact meps.am.tour@gmail.com. Removing a kiosk archive does not remove copies already sent to an email provider or previously copied to the shared folder; those copies must be addressed separately.
